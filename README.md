# Кухня трапезной

Приложение для подготовки задания на проектирование кухни трапезной: исходные данные, помещения, подключения, подбор оборудования, план расстановки, инженерия, смета и задание в PDF.

**Открыть приложение:** https://apptreefactory.github.io/trapeznaya/

Приложение — один файл `index.html`, работает в браузере и без интернета. Проекты хранятся в браузере пользователя; чтобы не потерять проект или передать его, скачайте его файлом через меню «Проект».
