# Кухня трапезной

Приложение для подготовки задания на проектирование кухни трапезной: исходные данные, помещения, подключения, подбор оборудования, план расстановки, инженерия, смета и задание в PDF.

**Открыть приложение:** https://apptreefactory.github.io/trapeznaya/

**История версий:** https://apptreefactory.github.io/trapeznaya/versions/ — каждая версия открывается по своей ссылке.

Приложение — один файл `index.html`, работает в браузере и без интернета. Проекты хранятся в браузере пользователя; чтобы не потерять проект или передать его, скачайте его файлом через меню «Проект».

## Как устроены версии

- `index.html` в корне — актуальная версия.
- `v/<номер>/index.html` — копия каждой выпущенной версии, после выпуска не меняется.
- `versions/index.html` — страница истории; список версий записан в ней в начале скрипта.

Выпуск версии: обновить `index.html`, скопировать его в `v/<новый номер>/`, добавить запись в начало списка на странице истории, сделать коммит.
